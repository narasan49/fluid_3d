# Fluid 3D

[Bevy Engine](https://bevy.org/)を活用した、格子法による3Dの流体シミュレーションのデモプロジェクトです。

## 概要
2次元の流体シミュレーションを実装した知見(https://github.com/narasan49/bevy_eulerian_fluid)をベースに、3次元の流体シミュレーションを実装しました。

主な実装内容は以下のようになります:

- **MACグリッドとCollocatedグリッドの併用**: CollocatedグリッドとMACグリッドの併用により、MACグリッドの精度を可能な限り維持しつつ、移流の計算などではCollocatedグリッドを用い、テクスチャサンプルの削減による高速化を図りました。
- **計算領域同士の接続**: 大きな格子の計算領域を確保することで大きな流体の流れを表現できますが、3D空間で流体の存在しない領域の割合が大きくなってしまう可能性があります。このような大きな格子では無駄なメモリや計算コストが発生してしまいます。そこで、複数の計算領域を合成可能にし、水の流れに沿った計算領域を設定できるようにしました。
- **自由表面**: レベルセット(流体とそれ以外をそれぞれ表すSDF)によって自由表面を表現しています。また毎フレーム、レベルセット=0となる面をMarching Cubesによりメッシュを生成して、Indirect Drawによる描画を行っています。ライティングは簡易的に、光源を固定したlambert散乱で行っています。
- **Multigrid法**: 圧力投影と呼ばれる圧力場を求める工程ではGauss-Seidel法による反復計算を行っています。この際、Multigrid法というMipMapのように階層的な解像度のテクスチャを利用して効率的に解を収束させる方法を採用しています。
- **剛体から流体へのインタラクション**: 動く配置物で大きな波を起こしたり、プレイヤーが触れることで水面が揺れる様子を観察できます。今回使用した形状はカプセル、直方体、三角柱です。

## 今後の発展
今後、以下のような方向性でさらに発展させることを考えています:
- **大規模な流体シミュレーション**: クリップマップのように、カメラの視点付近を中心に高解像度の小さい流体、中解像度の中程度の流体、低解像度の大きな流体領域を合成し、高・中解像度はカメラの視点に固定することで大規模な流体シーンを構築できると考えます。
- **さらなる高速化**
    - シミュレーションの計算中には水面付近のみなど、限られた領域のみ計算すればよいパスがいくつか含まれています。計算すべき領域をGPUで抽出してIndirect Dispatchすることでさらなる高速化が見込まれます。
    - 他にも主要なボトルネックではありませんが、剛体のSDFを毎フレーム計算しているため、Staticな剛体のSDFは再計算しないなど最適化の余地があります。
- **流体から剛体へのインタラクション**: 流体と剛体の境界における圧力勾配から剛体に働く力・トルクを求めることで流体から剛体へはたらく浮力を表現することが可能になります。
